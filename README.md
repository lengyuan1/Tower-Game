# Tower Building Game

Jeu web 3D de construction de tour développé en JavaScript.

## Description
Le but est d'empiler les blocs le plus précisément possible pour construire la tour la plus haute. Chaque partie mal alignée réduit la taille du bloc suivant.

## Technologies
- HTML5 / CSS3
- JavaScript (ES6+)
- Three.js
- GSAP
