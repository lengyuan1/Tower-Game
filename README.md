# 🏗️ 3D Tower Building Game (Jeu de Tour 3D)

Un mini-jeu web interactif de construction de tour en 3D, développé en JavaScript avec Three.js et GSAP.

## 🕹️ À propos du jeu / About the game
Ce projet est un jeu d'adresse où le joueur doit empiler des blocs mobiles avec précision pour construire la plus haute tour possible. Chaque bloc mal aligné est coupé, réduisant la surface de pose pour le bloc suivant.

## 🛠️ Technologies utilisées / Tech Stack
* **Langages :** HTML5, CSS3, JavaScript (ES6+)
* **Bibliothèques 3D & Animation :** Three.js (WebGL), GSAP (TweenLite)

## 🚀 Fonctionnalités / Features
* Rendu 3D interactif et gestion de la caméra via Three.js.
* Détection de collision en temps réel sur les axes X et Z.
* Animations fluides de chute de blocs et de fin de partie.
* Interface entièrement localisée en français.
